ておく adds an action done now for the sake of later, set aside and left that way. 予約しておく — make the reservation now — isn't just doing the reservation; it's doing it AND setting it aside as handled, so future-you doesn't have to think about it again.

The action itself can be anything; what ておく adds is always the same — do this now, so it's ready, done, or out of the way by the time it matters.

@@ tldr

ておく marks an action done now so it's ready, settled, or out of the way later.
とく is how ておく is actually said in casual speech.
ておこう is that same preparation as a decision the speaker is making right now — one form within the volitional paradigm, not a rule about volitionals generally.

@@ main

**Form:** `V-て + おく`

- **ておく marks a present action as preparation for a later need** — 予約しておく — I'll make the reservation [now, so it's set] — the reservation itself is ordinary; ておく is what frames it as advance work.
- **The later need doesn't have to be named** — 言っておく — I'll mention it [and leave it handled] — works whether or not the sentence says what the mention is preparing for.
- **ておく can also mean leaving something as it is, on purpose, rather than actively preparing it** — そのままにしておく — leave it as it is — treats not touching it as the deliberate choice being set aside for later.

```ex
来週[らいしゅう]は出張[しゅっちょう]だから、資料[しりょう]をコピーしておいた。
en: Since I've got a business trip next week, I made copies of the materials in advance.
note: The copying happens now; ておいた frames it as already handled, ready for a need that hasn't arrived yet.
bd: 来週は出張だから、|since I've got a business trip next week / 資料をコピーしておいた*|I made copies in advance
pat: V-ておく, preparation for a stated later need
```

@@ te-oita — ておいた, the preparation already made

**Form:** `V-ておいた` (past)

- **ておいた is where the preparation shows up as a completed fact** — most real ておく sentences describing what's already been done use this past form, since being prepared is usually a claim about something that already happened.
- **It survives register changes untouched** — セットしておいた — I set it up in advance — stays セットしておきました — I set it up in advance — in polite speech; only the ending changes, not the preparation itself.

```eg
準備[じゅんび]しておいた。 | I got it ready in advance.
```

@@ te-oku-to — ておくと, framing a tip

**Form:** `V-ておく + と`

- **ておくと presents the preparation as leading naturally to a stated benefit** — 早めに出しておくと、間に合うよ — if you send it early, you'll make it in time — states the preparatory action, then と carries it straight into what naturally follows from having done it.
- **This is と's own natural-consequence job, just built on top of ておく** — one line is enough here: と states that doing the first thing leads, as a matter of course, to the second.

-> Prerequisite: [[to#natural-consequence]] — と's natural-consequence reading, which this tip frame is built on

```eg
早[はや]めに薬[くすり]を飲[の]んでおくと、楽[らく]になるよ。 | If you take the medicine ahead of time, you'll feel better.
```

@@ te-okou — ておこう, deciding to prepare now

**Form:** `V-ておこう` (volitional)

- **ておこう is the speaker committing to the preparation right now, not just describing it** — 干しておこう — I'll get this aired out [while I can] — decides to do the preparatory action, rather than reporting that it was or will be done.
- **This is ておく riding on the volitional form, one point within that larger paradigm** — the volitional itself, what it does on every other verb, is its own construction with its own page.

-> Prerequisite: [[ikoukei]] — the volitional form ておこう is built on

```eg
梅雨[つゆ]に入[はい]る前[まえ]に、布団[ふとん]を干[ほ]しておこう。 | Let's get the futon aired out before the rainy season starts.
```

@@ toku — とく, how ておく actually gets said

**Form:** `V-て + おく → V-とく`

- **とく is simply ておく said in casual conversation** — dropping the お and merging it into the て is not a separate word; it's the everyday pronunciation.
- **The contraction attaches to every reading above** — 買っとく — I'll pick it up [in advance] — 言っとく — I'll mention it [and leave it handled] — carrying preparation, tip framing, and the volitional とこう all at the casual register.

```eg
polite: ビールを買[か]っておきます。 | I'll go buy some beer, ready for later.
casual: ビール買[か]っとく。 | I'll grab some beer.
```

```dialog
note: B's とく carries the same advance-preparation reading as ておく, just said the way it actually comes out between people who live together.
A: 今夜[こんや]、飲[の]む？ | Drinking tonight?
B: いいね。ビール買[か]っとくよ。冷[ひ]やしとくから。 | Sounds good — I'll grab some beer and get it chilling.
```

### In conversation

とく carries over into its own volitional and negative forms the same way ておく does: とこう — I'll get it done — とかない — I won't bother preparing it — both keeping the same preparation sense, just contracted.
