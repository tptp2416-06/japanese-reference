Imagine a line between an old situation and a new one.

もう looks back from the far side of that line: the change has been reached. まだ looks toward the line from the near side — the earlier situation remains, or the change hasn't happened yet.

That picture explains why neither word has a single fixed English translation. The adverb locates you relative to the line; the predicate says what is true there.

With an affirmative predicate, もう usually becomes already, and まだ becomes still. With a negative one, もう becomes not anymore, and まだ becomes not yet.

The line is set by the conversation. It might be the end of a task, the start of
a new state, or simply the point at which someone expected things to change.

@@ tldr

もう places the situation beyond a relevant change; まだ places it before that
change. Affirmative: もう becomes already or now, まだ becomes still. Negative:
もう becomes not anymore, まだ becomes not yet.

@@ mou

**Form:** `もう + affirmative predicate` · `もう + negative predicate`

- **The relevant change is behind you** — もう大丈夫 — it is okay now — presents
  becoming okay as reached, and もう遅い does the same for a limit already passed.
- **Negation changes what is true beyond the line** — もう使わない — I won't use
  it anymore — and もう寒くない place things on the earlier side the same way.
- **Expectation colors the reading** — もう can convey surprise that the line
  was crossed early, impatience that it should be crossed now, or no special
  emotion at all. The sentence and situation supply that tone.

```eg
もうここには住[す]んでいない。 | I don't live here anymore.
```

### Polarity, not もう, decides the English word

Already fits when the predicate names the new situation directly: もう終わった
— it has already finished. When the predicate is negative, the same viewpoint
means the old situation no longer holds: もう開いていない — it is not open
anymore.

The grammar has not reversed. もう keeps placing the viewpoint beyond a
contextual change; affirmation or negation determines what holds there.

@@ mou-kako

**Form:** `もう + V-た`

The past form makes the crossed line especially easy to see. An event has
happened, and もう presents it as reached by now or by another reference time.

- **In a statement, English usually says already** — もう予約した — I've
  already made a reservation.
- **In a question, English often says yet** — Japanese asks with もう whether
  the event side has been reached; English normally phrases the same neutral
  question with yet.
- **Earlier than expected is an implication, not a requirement** — もう終わった
  — it has already finished — can sound surprised, but it can also be a plain
  status report.

```ex
もう宿題[しゅくだい]は終[お]わった？
en: Have you finished your homework yet?
note: The question asks whether finishing has been reached. A positive answer can repeat もう; a negative answer normally switches to まだ.
bd: もう*|yet / 宿題は|the homework / 終わった|finished
pat: もう + V-た in a question
```

### The answer's polarity flips the adverb

Asked もう食べた？ — have you eaten yet? — a positive answer can be
うん、もう食べた — yes, I've already eaten; a negative one is normally
いや、まだ食べていない — no, I haven't eaten yet.

The answer changes the adverb because it changes the side of the line being
reported: reached with もう, still unreached with まだ.

@@ mada

**Form:** `まだ + affirmative predicate`

- **The earlier situation continues** — まだ寝ている — is still sleeping —
  while まだ雨だ shows the same pattern: an expected change hasn't displaced
  the current state.
- **The endpoint can feel close** — まだ大丈夫 — it is still okay — guarantees
  the current state, not its future. In the right setting, that can reassure
  and warn at the same time.
- **The approaching limit is contextual** — まだ若い — is still young — may
  contrast the present with a later stage, but まだ itself does not calculate
  when that stage will arrive.

```eg
店[みせ]はまだ開[あ]いている。 | The shop is still open.
```

### まだ大丈夫 can reassure or warn

It directly says only that things remain okay now. If the conversation has
already put a limit in view, "still" can suggest that the margin is shrinking:
まだ大丈夫 — it is still okay for now.

Without that setting, it can be simple reassurance instead. The warning is an
inference from context, not a second dictionary meaning built into まだ.

@@ mada-nai

**Form:** `まだ + negative predicate`

まだ with a negative predicate says the change hasn't been reached:
まだ終わっていない — it hasn't finished yet. まだ決めていない works the same way.

- **The negative belongs to the predicate** — まだ does not itself mean "not";
  it holds the viewpoint before the change, and the negative says that the new
  event or state is absent there.
- **Yet often leaves the change open** — まだ来ていない — hasn't arrived yet —
  commonly presents arrival as expected or relevant. It does not promise that
  the person will eventually arrive.
- **Questions keep the same viewpoint** — まだ終わっていない？ — is it not
  finished yet? — asks whether the unreached state continues and may sound
  impatient if the situation supplies that expectation.

!!! warning "Pitfall"
    Do not assign one English word to each adverb before looking at the
    predicate.

    もう is not confined to already: with a negative predicate it
    readily means not anymore. まだ is not confined to still: with a
    negative predicate it readily means not yet.

    The reliable order is viewpoint first, polarity second. Ask whether the
    relevant change is presented as reached or unreached, then read what the
    affirmative or negative predicate says on that side.

| viewpoint | predicate | natural example |
|---|---|---|
| beyond the change | affirmative | もう終わった — it has already finished |
| beyond the change | negative | もう働いていない — isn't working anymore |
| before the change | affirmative | まだ働いている — is still working |
| before the change | negative | まだ終わっていない — hasn't finished yet |

@@ mada-te-iru

**Form:** `まだ + V-ている` · `まだ + V-ていない`

ている contributes its ordinary reading: an action in progress, a continuing
state, or a state left by a change. まだ then says that this situation continues;
with ていない, it says that the relevant event or state has not been reached.

-> Continue with: [[te-iru#progressive]] — ている's own range of readings, only one of which まだ layers onto here

| combination | example in context |
|---|---|
| もう＋ている | もう働いている — has already started working |
| まだ＋ている | まだ働いている — is still working |
| もう＋ていない | もう働いていない — isn't working anymore |
| まだ＋ていない | まだ働いていない — hasn't started working yet |

All four can be ordinary Japanese when the context supplies the corresponding
change. In particular, もう覚えていない — I don't remember it anymore —
もう住んでいない, and もう働いていない are all natural uses of もう with ていない.

### The whole combination decides the translation

ている does not fix the translation on its own. The affirmative まだ＋ている
often reads as still, because an action or state continues: まだ読んでいる —
is still reading. Negating the same form changes the result: まだ読んでいない
— hasn't read it yet.

The translation comes from the whole combination. It is not a special meaning
hidden inside ている.

??? note "Where the threshold picture stops"
    The line is a mental model for organizing the contrasts, not a grammatical
    object inside the sentence. Japanese grammar supplies an adverb, a predicate
    and its polarity; speakers infer the relevant change from the situation.

    A separate use of もう adds another unit, as in もう一度 — one more time —
    and もう一杯. That enumerative pattern follows a different track and is
    outside this page.
