も takes one item and places it beside something already in view. If one person
is going, 私も行く "I'm going too" adds me; if one thing was read, 本も読んだ
"I read the book too" adds the book.

The position of も matters because the item it attaches to is the item being
added.

@@ tldr

も marks its item as another member of a set: "also", "too" or "as well". It
replaces が・を・は, but follows other case particles: にも, でも, とも.

@@ also

**Form:** `N + も` · `N + particle + も`

- **One more member joins the set** — 私も行く "I'm going too" assumes that
  someone else is going or that another relevant case is already in view.
- **Attachment sets the focus of the addition** — 私も本を読んだ "I, too, read
  the book" adds the reader; 本も読んだ "I read the book too" adds the book to
  other things read or done.
- **が・を・は give their place to も** — the added subject, object or topic is
  marked directly with も: 私も行く "I'm going too", 本も買った "I bought a
  book too".
- **Other case particles remain before も** — 東京にも行った "I went to Tokyo
  too", 学校でも話した "I talked about it at school too", 友達とも相談した "I
  also discussed it with a friend".

```ex
私[わたし]も本[ほん]を読[よ]んだ。
en: I, too, read the book.
note: も attaches to 私, so the added member is the reader rather than the book.
bd: 私も*|I too / 本を|the book / 読んだ|read
pat: N + も, added subject
```

### Which particle stays beside も?

| role before adding も | resulting shape | example |
|---|---|---|
| subject marked by が | が is replaced | 私も行く "I'm going too" |
| object marked by を | を is replaced | お茶も飲んだ "I drank tea too" |
| topic marked by は | は is displaced | 今日は休みで、明日も休みだ "today is a day off, and tomorrow is too" |
| に・で・と and other case relations | the particle remains; も follows | 京都にも行く "I'll go to Kyoto too" |

This page covers additive も. The scalar pattern 数量＋も "as many as／as much
as" has its own page, as do the question-word patterns 何も〜ない and 何でも.
