# もう vs. まだ — The 閾値しきいち Adverbs

## もう行いった？ / まだ行いってない。

---

## JLPT Level {#jlpt-level}

!!! abstract "JLPT Level — N5 Foundation / N4 Core"
The basic polarity pair (もう…た vs. まだ…ていない) is N5 — the first temporal adverbs every learner encounters. But the pragmatic depth — the emotional weight of もう as surrender or threshold-crossing, the persistence implied by まだ, and the negative-polarity flip where もう means "anymore" — solidifies at N4. This page maps the full temporal and emotional terrain.

```
| Tier | Pattern | Description | Example |
|------|---------|-------------|---------|
| N5 — Foundation | 〜た | Past completion | <ruby>行<rt>い</rt></ruby>った。 |
| N5 — Foundation | 〜ている | Ongoing state | <ruby>行<rt>い</rt></ruby>っている。 |
| **N5 — Foundation ← You are here** | **もう…た** | **Already completed** | **もう<ruby>行<rt>い</rt></ruby>った。** |
| **N5 — Foundation ← You are here** | **まだ…ていない** | **Not yet completed** | **まだ<ruby>行<rt>い</rt></ruby>っていない。** |
```

## Quick Summary {#quick-summary}

!!! tip "At a glance"
- **もう** marks a **crossed threshold**. It looks forward from a completed change and says "that line is behind us". In affirmative past sentences, it means **already**. In negative sentences, it means **not anymore / no longer**.
- **まだ** marks an **uncrossed threshold**. It looks at a continuing state and says "that line is still ahead" or "we are still on this side of it". In negative sentences, it means **not yet**. In affirmative sentences, it means **still**.
- The two adverbs form a **polarity mirror**: what もう asserts as done, まだ asserts as undone. What もう negates as finished, まだ affirms as continuing.
- **もう** with a negative often carries **emotional finality**: もう食べない can mean "I won't eat anymore" (decision) or "I don't eat that anymore" (habit end). It is the grammar of **surrender, refusal, or completion**.
- **まだ** with an affirmative often carries **emotional persistence**: まだ大丈夫 means "it's still okay" (but the clock is ticking). It is the grammar of **holding on, patience, and remaining margin**.
- **もう一度** is a separate idiom meaning "one more time" — the もう here is not temporal "already" but enumerative "another".
- **まだまだ** doubles the adverb to mean "still a long way to go" or "not by a long shot" — the grammar of humble deflection or cheerful persistence.

## Core Meaning {#core-meaning}

!!! note "Core Rule"
Use もう when you want to say that a state has been reached, a limit crossed, or a process completed — looking back at the threshold from the far side. Use まだ when you want to say that a state persists, a limit remains distant, or a process is incomplete — looking at the threshold from the near side.

| もう食たべた。 | I already ate [completion]. |
| --- | --- |
|  | *Context: The speaker is no longer hungry. The threshold of "having eaten" is behind them.* |

| まだ食たべていない。 | I haven't eaten yet [incompletion]. |
| --- | --- |
|  | *Context: The speaker is still hungry. The threshold of "having eaten" is ahead of them.* |

| もう行いかない。 | I won't go anymore / I don't go anymore [cessation]. |
| --- | --- |
|  | *Context: The speaker has reached their limit. The threshold of "going" is closed. This can be a decision or a habit termination.* |

| まだ行いっている。 | I'm still going / I still go [persistence]. |
| --- | --- |
|  | *Context: The action continues. The threshold of "stopping" has not been reached.* |

| もうここだ。 | We're already here [arrival]. |
| --- | --- |
|  | *Context: The destination threshold is crossed. Surprise or confirmation.* |

| まだここだ。 | We're still here [remaining]. |
| --- | --- |
|  | *Context: The departure threshold is uncrossed. Impatience or reassurance.* |

## The Polarity Matrix {#the-polarity-matrix}

This is the central logic of もう/まだ. The same adverb flips meaning depending on whether the predicate is affirmative or negative.

|  | Affirmative | Negative |
| --- | --- | --- |
| **もう** | **Already** — completion confirmed | **Anymore / No longer** — cessation confirmed |
|  | もう来きた。 (Already came.) | もう来こない。 (Won't come anymore.) |
|  | もう終おわった。 (Already finished.) | もう終おわらない。 (Won't finish anymore / No longer finishes.) |
| **まだ** | **Still** — persistence confirmed | **Not yet** — incompletion confirmed |
|  | まだ来きている。 (Still coming.) | まだ来きていない。 (Hasn't come yet.) |
|  | まだ終おわっている。 (Still finished — i.e., remains done.) | まだ終おわっていない。 (Hasn't finished yet.) |

!!! note "The matrix is absolute"
You cannot swap もう and まだ while keeping the same polarity and expect the same meaning. もう来ていない is ungrammatical/unnatural. まだ来た is ungrammatical/unnatural. The adverb and the predicate polarity are locked together.

!!! note "もう + negative = emotional weight"
もう来ない is not a neutral schedule update. It carries finality: "That phase is over". A parent saying もう来ない to an adult child leaving home is not stating a timetable — they are mourning a chapter's end.

!!! note "まだ + affirmative = ticking clock"
まだ大丈夫 is reassuring on the surface, but it implies a future limit. "It's still okay [but it might not be soon]". The grammar carries the faint pressure of impending change.

## Deep Dive: もう — The Threshold Crossed {#deep-dive-mou}

### Temporal もう: Already

もう with past-affirmative predicates asserts that an expected or scheduled event has occurred ahead of the reference time.

| もう春はるだ。 | It's already spring [seasonal threshold]. |
| --- | --- |
|  | *Context: The speaker notices cherry blossoms and realizes winter is fully behind them. The threshold was crossed perhaps unexpectedly early.* |

| もう終おわったの？ | Are you already finished? [surprise]. |
| --- | --- |
|  | *Context: The speaker expected the task to take longer. もう encodes the gap between expected and actual completion time.* |

| もうそんな時間じかん？ | Is it already that late? [alarm]. |
| --- | --- |
|  | *Context: Looking at the clock and discovering the hour. もう marks the threshold of lateness as crossed.* |

### Cessational もう: Not Anymore

もう with negative predicates asserts that a process or state has permanently or decisively ended.

| もう飲のまない。 | I won't drink anymore [decision]. |
| --- | --- |
|  | *Context: A vow. The threshold of drinking is closed. This is the grammar of resolutions.* |

| もう会あえない。 | We can't meet anymore [fate]. |
| --- | --- |
|  | *Context: Separation. The negative potential + もう creates a sense of final, irreversible loss.* |

| もう子こ欲よ供どもじゃない。 | I'm not a child anymore [maturation]. |
| --- | --- |
|  | *Context: Growing up. The state of childhood is definitively behind the speaker.* |

### Emotional もう: Surrender and Exasperation

もう detaches from literal time and becomes an emotional particle of **giving up, having had enough, or yielding**.

| もういい。 | That's enough / I give up / Forget it [surrender]. |
| --- | --- |
|  | *Context: The most emotionally loaded もう sentence. It can mean "stop" (to someone annoying), "I don't care anymore" (to a debate), or "it's fine now" (accepting an apology). Context and intonation determine which.* |

| もう疲つかれた。 | I'm already exhausted [threshold of endurance crossed]. |
| --- | --- |
|  | *Context: Not merely "I am tired" but "my limit has been reached." もう amplifies the fatigue into a crisis.* |

| もう我が慢まんできない。 | I can't take it anymore [breaking point]. |
| --- | --- |
|  | *Context: The negative potential + もう creates a pressure-cooker release. The threshold of patience is shattered.* |

### Enumerative もう: One More

もう一度, もう一回, もう一つ use もう not as temporal "already" but as **"another / one additional."** This is a separate lexical track.

| もう一いち度ど言いって。 | Say it one more time [request]. |
| --- | --- |
|  | *Context: The speaker wants a repetition. もう here counts iterations, not time.* |

| もう一いっ杯ぱい。 | One more cup / One more glass [order]. |
| --- | --- |
|  | *Context: At a bar or café. もう marks the addition of one unit to the current count.* |

!!! warning "Do not confuse temporal and enumerative もう"
もう来た ("already came") and もう一回来た ("came one more time") are different grammars. Context and particles disambiguate.

## Deep Dive: まだ — The Threshold Uncrossed {#deep-dive-mada}

### Persistence まだ: Still

まだ with affirmative predicates asserts that a state or action continues beyond the expected endpoint.

| まだ雨あめが降ふっている。 | It's still raining [weather persistence]. |
| --- | --- |
|  | *Context: The speaker expected the rain to stop by now. まだ marks the gap between expected and actual cessation.* |

| まだ若わかい。 | Still young [state persistence]. |
| --- | --- |
|  | *Context: Reassurance or self-deprecation. The state of youth continues despite circumstances that might suggest otherwise.* |

| まだ会社かいしゃにいる。 | I'm still at the company [location persistence]. |
| --- | --- |
|  | *Context: Working overtime, or still employed when others have left. The threshold of departure is uncrossed.* |

### Incompletion まだ: Not Yet

まだ with negative predicates asserts that an expected or required event has not occurred.

| まだ終おわっていない。 | I haven't finished yet [task incompletion]. |
| --- | --- |
|  | *Context: The standard response to "are you done?" まだ softens the negative into a statement of ongoing process rather than failure.* |

| まだ来きていない。 | They haven't arrived yet [arrival incompletion]. |
| --- | --- |
|  | *Context: Waiting. まだ makes the absence feel temporary rather than problematic.* |

| まだ分わからない。 | I don't know yet [knowledge incompletion]. |
| --- | --- |
|  | *Context: Processing new information. まだ frames ignorance as a transitional state, not a fixed condition.* |

まだ with potential or conditional negatives asserts that a window remains open — the threshold of impossibility has not been reached.

| まだ間まに合あう。 | We can still make it [possibility open]. |
| --- | --- |
|  | *Context: Racing against a deadline. まだ marks the remaining margin as sufficient.* |

| まだ遅おそくない。 | It's not too late yet [judgment open]. |
| --- | --- |
|  | *Context: Encouragement. The threshold of "too late" is uncrossed, so action is still viable.* |

| まだ大丈だいじょ夫ぶだと思おmoう。 | I think it's still okay [assessment]. |
| --- | --- |
|  | *Context: Managing a crisis. まだ holds the line against panic.* |

### Intensified まだ: まだまだまだ

Doubling まだ creates either **humble deflection** or **cheerful persistence**.

| まだまだです。 | I'm still far from done / I have a long way to go [humble]. |
| --- | --- |
|  | *Context: Standard response to praise. The speaker deflects by asserting that the threshold of mastery is distant.* |

| まだまだ終おわらないよ。 | We're nowhere near finished [persistence]. |
| --- | --- |
|  | *Context: Team morale. The doubled まだ turns endurance into a virtue.* |

| まだまだ若わかいね。 | You're still very young [reassurance / mild condescension]. |
| --- | --- |
|  | *Context: Older speaker to younger. The doubling softens the age gap into encouragement.* |

## Temporal vs. Spatial: もうそこ vs. まだここ {#temporal-vs-spatial}

The core semantic architecture of both markers maps identically across spatial domains.

| もうそこだ。 | It's already there / We're already there [spatial arrival]. |
| --- | --- |
|  | *Context: The destination is reached. The spatial threshold is crossed.* |

| まだここだ。 | We're still here [spatial remaining]. |
| --- | --- |
|  | *Context: The departure point persists. The spatial threshold of leaving is uncrossed.* |

| もうあのレベルだ。 | That's already at that level [abstract attainment]. |
| --- | --- |
|  | *Context: Assessing skill or quality. The threshold of the referenced level is behind the subject.* |

| まだこのレベルだ。 | It's still at this level [abstract remaining]. |
| --- | --- |
|  | *Context: Assessing stagnation. The threshold of advancement is uncrossed.* |

## In Real Life {#in-real-life}

!!! example "In Real Life — The Restaurant Check"
**Situation:** Two friends have finished eating. One reaches for the bill, but the other stops them.

```
> A: もうお<ruby>金<rt>かね</rt></ruby><ruby>払<rt>はら</rt></ruby>った？
*"Did you already pay?"*

> B: まだだよ。<ruby>待<rt>ま</rt></ruby>って。
*"Not yet. Wait."*

**Why もう fits A:** The payment threshold is a binary state. A is checking whether it has been crossed.

**Why まだ fits B:** The incompletion is stated without apology. まだ turns "no" into "not yet" — a promise of imminent action rather than a refusal.

**What もうじゃない would change:** もうじゃない ("It's not already") is unnatural. The polarity matrix is strict.

```

!!! example "In Real Life — The Breaking Point"
**Situation:** ユいは混雑した電車に乗っており、面接に遅れそうです。酔っぱらいの男が何度も彼女にぶつかってきます。ついに彼女は限界に達し、鋭い口調で言いました。

```
> もういい<ruby>加<rt>か</rt></ruby><ruby>減<rt>げん</rt></ruby>にして！

*"Enough already! Cut it out!"*

**Why もう fits:** This is emotional もう — the threshold of patience is definitively crossed. もういい加減にして is a set expression of exasperation. The もう does not mean "already" in a clock sense; it means "I have reached my limit".

**What まだいい加減にして would change:** Ungrammatical/unnatural. まだ cannot encode breaking points.

```

!!! example "In Real Life — The Encouragement"
**Situation:** A junior employee is struggling with a report. The deadline is tight. Their senior checks in.

```
> まだ<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>うから、<ruby>焦<rt>あせ</rt></ruby>らなくていいよ。

*"We can still make it, so no need to rush."*

**Why まだ fits:** The margin is open. The threshold of "too late" is uncrossed. まだ transforms the deadline from a threat into a manageable boundary.

**What もう間に合う would change:** "We already can make it" — grammatically possible but pragmatically odd. It would imply the deadline was never a concern, removing the reassurance value.

```

## Grammar Analysis {#grammar-analysis}

### Function in Context

* もう食べた: もう asserts the completion of eating. The past tense た confirms the threshold is crossed. The speaker is now in the post-eating state.
* まだ食べていない: まだ asserts the incompletion of eating. The negative ていない confirms the threshold is uncrossed. The speaker remains in the pre-eating state.
* もう食べない: もう asserts the cessation of eating. The negative ない confirms the process is closed. The speaker has exited the eating state permanently or for the current occasion.
* まだ食べている: まだ asserts the persistence of eating. The progressive ている confirms the action continues. The speaker has not yet reached the stopping threshold.
* もういい: もう detaches from temporal logic and becomes an emotional particle. The adjective いい is affirmative, but the meaning is "that's enough" — a meta-linguistic use where もう modifies the speech act itself.

### Construction {#construction}

#### もう

| Predicate Type | Pattern | Example | Meaning |
| --- | --- | --- | --- |
| Past affirmative | もう + V-た | もう行いった | already went |
| Past affirmative (state) | もう + Adj-past | もう寒さむかった | was already cold |
| Negative plain | もう + V-ない | もう行いかない | won't go anymore |
| Negative plain (state) | もう + Adj-neg | もう寒さむくない | no longer cold |
| Negative potential | もう + V-potential-neg | もう行いけない | can't go anymore |
| Enumerative | もう + number/counter | もう一いち度ど | one more time |

#### まだ

| Predicate Type | Pattern | Example | Meaning |
| --- | --- | --- | --- |
| Progressive affirmative | まだ + V-ている | まだ行いっている | still going |
| State affirmative | まだ + Adj | まだ寒さむい | still cold |
| Negative plain | まだ + V-ていない | まだ行いっていない | hasn't gone yet |
| Negative plain (state) | まだ + Adj-neg | まだ寒さむくない | not cold yet |
| Potential affirmative | まだ + V-potential | まだ行いける | can still go |
| Intensified | まだまだ + predicate | まだまだだ | still far from done |

!!! warning "Do not use もう with ていない"
!!! failure "Incorrect"
もう行いっていない。
!!! success "Correct"
もう行いかない。 (Won't go anymore.)
まだ行いっていない。 (Hasn't gone yet.)

```
~This attempts to say "already not going," which is logically incoherent in Japanese. For "not going anymore," use simple negative: もう行かない. For "hasn't gone yet," use まだ: まだ行っていない.~

```

!!! warning "Do not use まだ with た"
!!! failure "Incorrect"
まだ行いった。
!!! success "Correct"
まだ行いっていない。 (Hasn't gone yet.)
もう行いった。 (Already went.)

```
~まだ asserts threshold-uncrossed; た asserts threshold-crossed. This is a direct contradiction.~

```

## Japanese Mindset {#japanese-mindset}

The もう/まだ pair encodes a cultural sensitivity to **process, patience, and social timing**.

* **もう as social pressure.** Asking もう終わった？ is not neutral — it implies "I expected this to be done by now, and I am checking whether you are behind or ahead". The adverb carries the weight of expectation.
* **まだ as social grace.** Answering まだです to a request for readiness is softer than いいえ. It frames delay as a temporary state rather than a failure. Japanese service culture relies heavily on まだ to soften negative reports.
* **Threshold anxiety.** Japanese communication often revolves around whether social thresholds have been crossed: もう知っている (already know — so don't explain further), まだ知らない (don't know yet — so please explain). The adverbs are tools of social coordination.
* **もういい as face-saving exit.** When a conversation becomes uncomfortable, もういい allows a speaker to withdraw without explicit confrontation. The grammar of "enough" becomes the grammar of social escape.
* **まだまだ as humble performance.** In response to praise, まだまだです is not merely modest — it is a social ritual that maintains hierarchy. The speaker asserts that the threshold of excellence is still distant, preserving the praiser's superior position.

## Nuance Comparison {#nuance-comparison}

| Grammar Point | Core Meaning | Threshold Logic | Emotional Register | JLPT |
| --- | --- | --- | --- | --- |
| もう…た | Already did | Crossed | Neutral to surprised | N5 |
| もう…ない | Not anymore | Closed | Final, decisive | N4 |
| もういい | That's enough | Breaking point | Exasperated / surrendering | N3 |
| もうすぐ | Very soon | Threshold approaching | Anticipatory | N3 |
| まだ…ている | Still doing | Uncrossed | Neutral to patient | N5 |
| まだ…ていない | Not yet | Uncrossed | Neutral to apologetic | N5 |
| まだ大丈夫 | Still okay | Margin remains | Reassuring / anxious | N4 |
| まだまだ | Still far | Distant | Humble / persistent | N3 |
| もう一度 | One more time | Iterative | Requesting | N4 |
| たった今いま | Just now | Threshold just crossed | Immediate | N4 |
| これから | From now on | Threshold ahead | Forward-looking | N5 |

**もう vs. たった今:** Both refer to recent completion. たった今来た ("just arrived now") emphasizes immediacy — the threshold was crossed seconds ago. もう来た ("already came") emphasizes the state change without urgency.

**まだ vs. これから:** Both refer to future-oriented states. まだ来ていない ("hasn't come yet") emphasizes current absence. これから来る ("will come from now") emphasizes future arrival. まだ looks at the uncrossed threshold; これから looks at the approaching action.

**もう vs. もうすぐ:** もう来た = already came (done). もうすぐ来る = coming very soon (almost done). The すぐ narrows the temporal gap to the threshold.

## Common Mistakes {#common-mistakes}

### 1. Using もう with negative-progressive (ていない)

!!! failure "Polarity clash"
もう行いっていない。

```
~This attempts to say "already not going," which is logically incoherent in Japanese. For "not going anymore," use simple negative: もう行かない. For "hasn't gone yet," use まだ: まだ行っていない.~

```

!!! success "Correct"
もう行いかない。 (Won't go anymore.)
まだ行いっていない。 (Hasn't gone yet.)

### 2. Using まだ with past affirmative

!!! failure "Polarity clash"
まだ行いった。

```
~まだ asserts threshold-uncrossed; た asserts threshold-crossed. This is a direct contradiction.~

```

!!! success "Correct"
まだ行いっていない。 (Hasn't gone yet.)
もう行いった。 (Already went.)

### 3. Confusing enumerative and temporal もう

!!! failure "Context error"
Interpreting もう一度 as "already one time."

```
~もう一度 means "one more time" — the もう is enumerative, not temporal. The speaker wants an additional iteration, not a report on completion.~

```

!!! success "Correct understanding"
もう一度 = one more time (enumerative)
もう行った = already went (temporal)

### 4. Using まだ in breaking-point contexts where もう is required

!!! failure "Emotional register error"
まだいい加減にして！

```
~Ungrammatical/unnatural. Breaking points require もう. まだ cannot encode threshold-crossing or exasperation.~

```

!!! success "Correct"
もういい加か減げんにして！

### 5. Translating "not yet" word-for-word without ていない

!!! failure "Aspect error"
まだ行いかない。

```
~This means "I still won't go" (refusal persistence), not "I haven't gone yet". For incompletion, the progressive aspect ていない is mandatory with action verbs.~

```

!!! success "Correct"
まだ行いっていない。 (Hasn't gone yet.)
まだ行いかない。 (Still won't go. — rare, implies ongoing refusal)

### 6. Using もういい as universal "it's good"

!!! failure "Pragmatic error"
Responding to "How was the meal?" with もういい。

```
~もういい in this context means "that's enough [stop asking]" — rude or confusing. For "it was good," use 美味しかったです.~

```

!!! success "Correct"
もういい。 (That's enough / I give up — to someone pushing you.)
もう大丈だいじょ夫ぶ。 (It's okay now — accepting an apology.)

## Hidden Points {#hidden-points}

* **もう and まだ are the grammar of social timing.** Asking もう帰るの？ ("Are you going home already?") can be neutral curiosity or passive-aggressive pressure depending on intonation. まだ帰らないの？ ("You're still not going home?") carries the same ambiguity.
* **The もう…た question is often a hint.** もう食べた？ can mean "Should we go?" or "Can I clear the table?" The temporal adverb is doing social work beyond literal time-checking.
* **まだ can express hope against evidence.** まだ生きている ("still alive") said at a disaster site carries the emotional weight of defying expectation. The grammar makes survival feel miraculous.
* **もう can express premature arrival.** もうそんな時間？ said at 10 PM implies the speaker lost track of time. The もう encodes surprise at the clock's betrayal.
* **まだ + negative + けど softens complaints.** まだ終わってないけど… ("I haven't finished yet, but…") is the standard Japanese way to ask for an extension without explicitly asking. The まだ frames the delay as natural, the けど invites listener accommodation.
* **もうすぐ and まだまだ are conversational bookends.** もうすぐ着く (almost there) and まだまだ遠い (still far) are the two poles of journey discourse. They structure narrative expectation.
* **The negative of もういい is not まだいい.** まだいい means "it's still okay [to continue]" or "it's not bad yet". It is not the antonym of もういい. There is no direct antonym — Japanese breaks the symmetry here.
* **まだ can attach to entire clauses.** まだ日本にいる間は ("While I'm still in Japan…") uses まだ to scope a temporal window. This is N3 clause-adverb usage.
* **もう in もう10年 also means "as many as."** もう10年も待った = "I waited as many as 10 years". This is a separate emphatic usage where もう amplifies quantity rather than marking completion.
* **Children use まだまだ to defy bedtime.** まだまだ遊びたい = "I still want to play a lot more". The doubling is inherently childlike and resistant.

## Learner Stage {#learner-stage}

| Stage | What It Looks Like |
| --- | --- |
| **Now — N5** | Produce basic polarity pairs: もう…た (already did) and まだ…ていない (not yet). Avoid mixing もう with ていない. Use まだ with negative for incompletion, affirmative for persistence. |
| **Developing — N5→N4** | Deploy もう…ない for cessation and refusal. Use まだ…ている for ongoing states. Recognize emotional もういい. Distinguish enumerative もう一度 from temporal もう. |
| **Automatic — N4→N3** | もう and まだ arrive as threshold markers before conscious analysis. You hear もう終わった？ and register social pressure. You hear まだです and parse it as graceful delay. You use まだまだ for humble deflection without thinking. |
| **Mastery** | You control the full temporal and emotional spectrum: temporal completion (もう来た), cessation (もう来ない), persistence (まだ来ている), incompletion (まだ来ていない), margin (まだ間に合う), surrender (もういい), humility (まだまだ), and enumeration (もう一度). You never confuse polarity, and you read the social subtext of threshold-checking instantly. |

## See Also {#see-also}

### Same Family

* たった今いま — Just now (immediate past)
* これから — From now on (immediate future)
* もうすぐ — Very soon / almost
* まだまだ — Still far / not by a long shot

### Commonly Confused With

* もう一いち度ど — One more time (enumerative, not temporal)
* しかも — Moreover (unrelated conjunction)
* もっと — More (quantity, not threshold)
* ずっと — Continuously (duration, not threshold)
* とっくに — Long ago (emphatic "already," more decisive than もう)

### Builds From

* Past tense た (N5) — Required for もう…た
* Negative forms ない (N5) — Required for もう…ない and まだ…ない
* Progressive ている (N5) — Required for まだ…ている and まだ…ていない
* Plain verb forms (N5) — Required for もうすぐ, まだ + potential

### Unlocks Next

* とっくに (N3) — Emphatic "already" (long since)
* 今いま更さら (N3) — "Now of all times" (belated realization)
* 未いだに (N3) — Formal/literary "still" (まだの漢語形)
* やっと (N4) — Finally (threshold just crossed with effort)
* ついに (N3) — Finally / at last (threshold crossed after long wait)
